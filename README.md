# 星露谷整合包 v2 · Stardew Valley Pack v2

一个开箱即用的星露谷 1.6 整合包：**电脑版 35 个模组 / 手机版 26 项**，解压后整包拖进 `Mods` 就能玩。
以自制的产业类模组为主（立体农业、沿岸渔业、垃圾回收机、林场矿场养殖场、瑞幸咖啡、中式食肆、茅台、金坷垃、小天才电话手表……），依赖全部随包附带。

## 电脑版安装

1. 装 [SMAPI](https://www.nexusmods.com/stardewvalley/mods/2400) 4.5.x（游戏 1.6.15 或更高）
2. 把压缩包里的 `Mods` 内容全部解压/拖进 `Stardew Valley/Mods`
3. 用 SMAPI 启动游戏

包里**不含 config.json**，第一次启动是干净的默认值。

## 手机版安装

需要安卓版 SMAPI + Cinderbox 环境，`Mods` 路径是 `/sdcard/StardewValley/desktop/Mods`
（注意是 `desktop` 子目录）。解压后整包放进去即可。

## Vortex 一键安装（推荐给电脑版用户）

懒得手动拖？用合集包：

1. 装 [Vortex](https://www.nexusmods.com/about/vortex/) 并登录 Nexus 账号
2. 左上角选 Stardew Valley → 左侧 `Collections`
3. 把 `StardewValleyPack-v2_合集包.zip` 拖进 Vortex 窗口
4. Vortex 会列出 33 个条目并自动下载安装

合集只含清单、不含模组文件，下载走 Nexus 官方渠道，模组作者照常拿到下载量。

## 注意事项

1. **版本差异**：立体农业 / 沿岸渔业 / 瑞幸咖啡 / 中式食肆 / 怪物竞技场 / 电话送礼 / 罗宾加班 的 Nexus 版本比整合包内略旧，整合包里是本机最新修复版。要完全一致请用整合包本体，不要用合集。
2. **手机版不含 Lookup Anything**，食肆与垃圾回收机在手机端每次载入会刷一些无害日志。
3. 手机包只做了静态校验与模拟器验收，真机触控仍需自测。
4. 联机：模组需要每位玩家各自安装；主机与客机的版本必须一致。
